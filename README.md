# ❤️ Heart Disease Risk Prediction Using Machine Learning

An end-to-end Machine Learning application that predicts the risk of heart disease based on patient health parameters. The project includes data preprocessing, model training, interactive visualizations, and a user-friendly Streamlit web application for real-time predictions.

---

## 🌐 Live Demo

https://heartdiseaseriskpredictionusingml-gslhb4ebp2nf3jr6278avr.streamlit.app/


---

## 📖 About

Heart disease is one of the leading causes of death worldwide. Early prediction can help individuals seek timely medical attention and adopt preventive measures.

This project uses a Machine Learning model trained on heart disease data to predict whether a patient is at risk based on clinical parameters such as age, chest pain type, cholesterol level, blood pressure, and maximum heart rate. The application also provides interactive visualizations to help users understand the dataset.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Anwaya-Anil/heart_disease_risk_prediction_using_ml.git
```

### Move into the project directory

```bash
cd heart_disease_risk_prediction_using_ml
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
streamlit run app.py
```

## 📊 Dataset

The project uses a Heart Disease dataset containing patient health information such as:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- ST Depression
- Slope
- Number of Major Vessels
- Thalassemia

The dataset is preprocessed before training the Machine Learning model.
